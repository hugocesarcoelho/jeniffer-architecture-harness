# Inputs do cliente

- `floorplans/`: plantas, fachadas, hidráulica, elétrica e pavimentos.
- `references/`: imagens e documentos de referência.
- `property-photos/<room_id>/`: fotos por ambiente.
- `supporting-documents/`: levantamentos, memoriais e outros arquivos.

Use nomes descritivos, por exemplo:

- `sala_parede_tv_01.jpg`
- `sala_janela_principal_02.jpg`
- `pavimento_terreo_planta_baixa.pdf`
